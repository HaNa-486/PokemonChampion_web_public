# Contributing

Start with the README, install the pinned dependencies, then make a small branch and run `pnpm verify`.

In the pull request, explain the problem, resulting behavior and relevant checks. For an interaction change, include a short reproduction or screenshot when useful. Keep the existing bilingual labels usable.

Keep samples small and clearly marked as demonstration data. Preserve the browser-only design, existing local saves and calculation limits. Do not add an upstream dump, game artwork, network integration, private deployment configuration or unrelated process records.

For new third-party code, data or assets, identify the original source and license before including it. Contributions are accepted under the project's MIT license for contributor-owned material; existing third-party terms remain in force.

Do not post secrets or personal data in issues. See [SECURITY.md](SECURITY.md) for security reporting.
