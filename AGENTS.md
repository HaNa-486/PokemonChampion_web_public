# Public portfolio contributor instructions

This is a standalone browser demo, not the live service or its deployment repository.

- Keep demonstration statistics visibly labelled and deterministic. Do not imply real usage, current eligibility, or live source freshness.
- Preserve the catalog, team, speed, damage and local save interactions. State calculation limits honestly.
- Do not add production identifiers, private history, upstream data dumps, game artwork, credentials or external data requests.
- Keep the MIT and third-party notices intact. Check permission before introducing new data or assets.
- Work on a `codex/*` branch. Run `pnpm verify` for code or fixture changes and review the relevant browser flow. Documentation-only corrections need consistency/link checks.
- Use the PR for change explanation and evidence. Do not create PDOS records, release ledgers, scheduled monitors or a separate maintenance process.
- There is no production deployment or private-site UAT in this repository. Publishing a website or adding external services needs an explicit request.
